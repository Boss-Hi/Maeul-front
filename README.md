# Maeul-front

Frontend application for Maeul.

## Getting Started

```bash
pnpm install
pnpm dev
```

## Package Baseline

This project is initialized with the preferred frontend package baseline:

- Next `16.2.2`
- React `19.2.4`
- Tailwind CSS `4.1.13`
- ESLint `9.39.1`
- Prettier `3.8.1`
- TypeScript `5.9.3`

Keep package changes intentional and avoid unrequested version upgrades.
